# ⚔ JaggerFighter — Pentest Suite

> Suite de pentest unifiée pour Kali Linux : Nmap, Nikto, Gobuster, Hydra, SQLMap, theHarvester + CVE Lookup automatique et rapports professionnels.

[![Platform](https://img.shields.io/badge/Platform-Kali%20Linux-red?style=flat-square)](https://www.kali.org)
[![Python](https://img.shields.io/badge/Python-3.10+-blue?style=flat-square)](https://python.org)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](LICENSE)

## Installation

```bash
git clone https://github.com/VOTRE_USER/jaggerfighter.git
cd jaggerfighter
sudo bash install.sh
```

## Utilisation

```bash
jf                              # Menu interactif
jf -t 192.168.1.1               # Scan interactif
jf -t 192.168.1.1 --quick       # Scan rapide
jf --history                    # Historique sessions
jf --report SESSION_ID          # Générer rapport
jf --activate JFPRO-XXXX-XXXX  # Activer licence Pro
jf --status                     # Statut licence
```
